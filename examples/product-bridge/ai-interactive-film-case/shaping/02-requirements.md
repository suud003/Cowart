# 分岔回声｜需求总表

> 本文是模块 PRD 的上位需求索引。`src-user-case-brief` 仅证明“用 AI 互动影游作为 case”；具体角色、流程和规则均为 AI 假设，需经评审后转为产品决策。

## 1. Actor 与权限边界

| Actor | 核心目标 | 允许 | 不允许 |
|---|---|---|---|
| 玩家 | 完成一段会响应行动的电影化故事 | 浏览已发布章节；创建自己的会话；选择或输入行动；查看自己的状态与结局 | 修改故事版本、规则红线或他人会话；直接写入状态 |
| 创作者 | 在可控边界内制作与测试互动章节 | 编辑草稿；定义约束/节拍/结局；预览；提交校验；发布新版本 | 修改平台安全规则；改变已开始会话所绑定的版本 |
| 内容评审 / 运营 | 审核风险并管理发布状态 | 查看版本与审计结果；批准、驳回、下架；触发抽样复核 | 直接替创作者无痕改稿；查看无权限的玩家自由文本 |
| AI 导演 | 在约束内计划下一回合 | 读取发布版本和当前会话；提出计划、对白和状态差量 | 绕过校验提交状态；改变硬约束；自建永久规则 |
| 规则 / 安全服务 | 验证输入、输出和状态差量 | 阻止、澄清、降级或记录风险内容 | 独立创作剧情；在无审计记录的情况下静默改写 |

## 4. 核心数据实体

| 实体 | 关键字段 | 所有权 / 生命周期 |
|---|---|---|
| `StoryProject` | projectId, ownerId, title, rating, status | 创作者；跨版本容器 |
| `StoryVersion` | versionId, projectId, compiledAt, checksum, publishStatus | 发布后不可变；玩家会话绑定 |
| `WorldBible` | facts, locations, timeline, hardRules | 创作者定义；进入约束编译 |
| `CharacterSpec` | goals, secrets, voice, hardNo, relationshipAxes | 创作者定义；版本化 |
| `BeatGraph` | beatId, purpose, preconditions, allowedTransitions, fallback | 创作者定义；允许汇流 |
| `EndingRule` | endingId, requiredState, excludedState, priority | 创作者定义；校验可达性 |
| `SessionState` | sessionId, versionId, turn, beat, relations, clues, goals, flags | 玩家会话；服务端权威 |
| `PlayerAction` | actionId, kind, rawText, normalizedIntent, idempotencyKey | 玩家产生；审计与隐私策略约束 |
| `ScenePlan` | objective, characterIntents, stateDeltaProposal, assetTags | AI 提议；未通过校验不可提交 |
| `ScenePayload` | dialogue, narration, choices, assetRefs, captions | 面向客户端；可缓存 |
| `TurnAudit` | inputs, modelRoute, checks, retries, before/after, latency, cost | 内部审计；按策略留存 |

## 5. 全局业务规则

1. **规则优先级**：平台安全 > 故事红线 > 世界/角色硬约束 > 当前会话事实 > 当前节拍目的 > 风格偏好。
2. **版本绑定**：`SessionState.versionId` 在会话创建后不可修改；下架版本可阻止新会话，但存量会话如何处理由运营策略决定。
3. **幂等提交**：相同 `sessionId + turn + idempotencyKey` 只允许一次有效状态提交。
4. **先计划后生成**：模型先返回结构化 `ScenePlan`；计划通过校验后才生成对白/旁白与资产标签。
5. **状态最小化**：每个状态变量必须有类型、范围、来源和可见性；禁止用无法校验的自由文本充当关键门槛。
6. **结局唯一性**：同一回合满足多个结局时按创作者显式优先级决定；无优先级则阻止发布。
7. **视觉不承载唯一事实**：关键线索必须同时存在于状态与可访问文本中，不能只藏在画面里。
8. **失败不推进**：模型超时、校验失败或渲染失败不得消耗回合或提交部分状态。
9. **隐私最小化**：自由文本只用于当前叙事、风控和必要审计；留存期、脱敏和删除能力待法务确认。

## 6. AI 回合输入 / 输出契约

### 输入

- 不可变：`StoryVersion` 摘要、世界硬规则、角色不可违背项、当前节拍允许迁移。
- 可变：最后已提交的 `SessionState`、最近回合摘要、玩家行动、可用视觉资产标签。
- 运行参数：模型路由、token 预算、超时预算、内容分级、语言。

### 结构化计划输出

- `normalizedIntent`：玩家意图与目标对象。
- `nextBeatId`：必须属于允许迁移集合。
- `characterIntents[]`：每个在场角色的动机与行动。
- `stateDeltaProposal`：类型化状态差量，不含直接提交权限。
- `assetTags[]`：只引用已登记标签。
- `explanationCodes[]`：供规则诊断，不直接暴露模型内部推理。

### 处理结果

- `ACCEPT`：生成场景并提交状态。
- `CLARIFY`：向玩家询问一个可回答的问题，不推进回合。
- `SAFE_MAP`：说明限制，并映射为同目标的安全行动，需玩家确认或按创作者策略执行。
- `REJECT`：说明无法执行，保持原状态并提供允许的替代项。
- `FALLBACK`：使用创作者预写的兜底节拍与对白。

## 7. 异常与边界场景

| 场景 | 预期行为 | 不得发生 |
|---|---|---|
| 空输入 / 仅空白 | 阻止提交并保持输入焦点 | 发送空回合 |
| 与世界规则冲突 | 澄清或给出世界内替代行动 | 为迎合玩家改写硬事实 |
| 违规或高风险输入 | 拒绝 / 安全映射；记录策略代码 | 回显不必要的违规内容 |
| 模型超时 | 显示进度；在预算内重试一次；之后走兜底 | 无限 loading 或重复推进 |
| 状态提交冲突 | 读取服务端最新回合；恢复 UI；提示已处理 | 覆盖新状态 |
| 视觉资产缺失 | 使用通用镜头 + 文本/音频承载事实 | 丢失关键剧情信息 |
| 网络中断 | 保留未发送输入；恢复最后已提交回合 | 本地假装成功 |
| 版本下架 | 阻止新会话；存量策略明确提示 | 无提示地切换到其他版本 |
| 多结局同时命中 | 按显式优先级；缺失时视为发布错误 | 运行时随机选结局 |

## 8. 范围外与待决策项

- 范围外：多人共同决策、UGC 素材交易、跨作品角色继承、实时视频生成、VR、玩家自建模型。
- `[Open]` 下架版本的存量会话是允许完成、强制终止还是迁移？
- `[Open]` 自由文本审计留存期、未成年人策略与地区合规要求。
- `[Open]` 玩家是否能关闭关系/线索变化提示以增强沉浸。
- `[Open]` 资产标签匹配失败时，通用兜底镜头的最低数量与制作成本。
